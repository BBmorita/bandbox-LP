# BandBox LP

BandBox（アーティスト向けグッズ販売サービス）のランディングページです。

## ローカルでの確認

依存関係やビルドは不要です。ブラウザで `index.html` を開いて確認してください。

## 編集方針

- LP本体は `index.html`、プライバシーポリシーは `privacy-policy.html` で管理します。
- 現在は `bandbox_lp_mock.html` をベースにした初期モックです。
- `【...】` と表示される箇所は、公開前に正式な文言・URL・画像へ差し替えます。
